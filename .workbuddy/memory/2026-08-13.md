## 简约玫瑰线条风重设计（14:50）

**问题反馈**：上一版太花哨——满屏玫红色、主题切换影响文字阅读、背景太重

**彻底重写方案（minimal rose-line style）**：

1. **背景回归干净**
   - 亮色：`#fafafa` 浅灰白 + 极淡玫瑰色点阵纹理（opacity 0.03）
   - 暗色：`#1a1a1a` 中性深灰 + 极淡粉色点阵（opacity 0.04）
   - 删除 `rose-bg.jpg` / `rose-bg-dark.jpg` 背景图引用
   - 删除所有 radial-gradient 大光斑层
   - 删除顶部发光光带

2. **去掉所有大面积玫瑰色填充**
   - Hero 卡片：白色半透明 + 细边框（不再玫瑰玻璃拟态）
   - 导航栏：透明毛玻璃 + 底部一条 60px 宽细玫瑰线
   - 卡片墙：白底 + 微妙阴影（不再玫瑰底色）
   - 标题/副标题：保持主题原色（不再强制渐变）

3. **玫瑰元素只作为细线点缀**
   - 导航底部：60px 渐变细线（唯一导航装饰）
   - 头像：1.5px 玫瑰描边环（去掉彩虹光环）
   - 卡片标题左侧：3px 玫瑰渐变竖条（opacity 0.6）
   - 链接颜色：柔和玫瑰色 `#c2185b`
   - hover 效果：极淡玫瑰底色 + 玫瑰边框
   - 选区高亮：极淡玫瑰透明底

4. **滚动条重新设计**
   - 6px 宽度（从 12px 缩小）
   - 亮色：中性灰，暗色：淡粉（不再渐变流动）
   - 去掉动画和复杂阴影

5. **头像缩小到 56px**
   - 去掉 conic-gradient 彩虹光环
   - 只保留 1.5px 玫瑰细描边 + 微阴影

6. **hugo.toml 清理**
   - 删除 `lightTheme = "autumn"` / `darkTheme = "synthwave"`（用 dream 默认 emerald/forest）
   - 删除 `backgroundImage` / `backgroundImageDark`

7. **HTML 清理**
   - 删除 🌹🌸 emoji 角标装饰
   - badge 标签去掉玫瑰前缀 emoji
   - 分隔线改为纯文字"最新文章"

**核心原则**：玫瑰是点缀不是主角，可读性第一，简约干净
