   - 主题自动在 about 翻页背面渲染 socials 卡片

4. **自定义炫酷 CSS**（`static/css/custom.css`）
   - 头像彩虹光环动画（双层 conic-gradient 旋转）
   - 标题渐变流光（5 色调 + 5s 循环）
   - 副标题渐变

   - 导航项 hover 下划线动效
   - 卡片悬浮 4D 阴影 + 上移
   - 滚动条渐变色

5. **hugo.toml 更新**
   - `avatar = "img/avatar.png"`、`favicon = "img/favicon.png"`、`email`
   - `footerBottomText` 自定义页脚签名

**坑点**：
- Hugo `params.advanced.customCSS` 不会过 `resources.Get`，必须放 `static/css/` 而不是 `assets/css/`
- Hugo 模板 `{{ .title }}` 不能写 `{{ ..title }}`，那是语法错误
- 系统中文字体（msyh/simhei）在 Pillow 默认 size=240 会渲染失败，用拉丁字母 P 替代
